방문별로 한 번씩 결과를 남겨요

결과를 남기기 전에는 일정을 변경하거나 취소해요. 결과가 저장된 뒤 다음 방문을 추가하고, 취소한 일정도 이력에 남겨요.

상황에 맞는 항목을 받아요

실제 방문일·방문자·현장 기록·결과는 필수이고, 사진은 선택이에요. ‘추가 조치 필요’를 선택하면 남은 작업과 후속 담당자도 필수로 받아요.

기존 서비스 코드를 참고한 독립 HTML 기획서예요. 실제 앱과 DB는 변경하지 않았어요. 화면 속 버튼은 설명용이며, 인쇄할 때도 모든 전후 화면이 함께 나와요.
