# Codex PR 리뷰 요청

지정된 GitHub PR에 다음 댓글을 정확히 게시한다.

```text
@codex review 발생 조건이 좁은 경우는 제외하고 일상 사용 기준으로 검토
```

`@codex review`는 정식 PR 리뷰를 시작하는 트리거다. `review`를 생략하거나 `@codex`를 Markdown 링크로 바꾸지 않는다. 앞뒤에 인사말, 설명, 이모지, 서명을 추가하지 않는다.

## 대상과 권한 확인

- 사용자가 댓글 게시를 명시적으로 요청했을 때만 원격 상태를 변경한다. 문구 작성, 사용법 질문, 검토 요청에 관한 상담은 게시 권한으로 간주하지 않는다.
- PR URL이나 저장소와 번호가 주어졌다면 그 대상을 사용한다.
- 사용자가 `현재 PR`이라고 했다면 현재 저장소와 브랜치에 연결된 PR을 읽기 전용으로 조회한다.
- 대상 PR을 하나로 확정할 수 없으면 추측해서 게시하지 말고 정확한 PR을 묻는다.

## 게시 절차

1. `gh pr view`로 PR의 URL, 번호, 제목, 상태를 확인한다.
2. 기존 댓글을 조회해 위 문구와 완전히 같은 댓글이 있는지 확인한다. 이미 있다면 중복 게시하지 않고 기존 댓글이 있음을 알린다.
3. 열린 PR이며 사용자의 게시 요청이 확인됐을 때 다음 형식으로 댓글을 등록한다.

   ```bash
   gh pr comment <PR> --body '@codex review 발생 조건이 좁은 경우는 제외하고 일상 사용 기준으로 검토'
   ```

4. 명령이 반환한 댓글 URL이나 후속 조회로 등록 결과를 확인하고 대상 PR과 함께 보고한다.

인증, 권한, 네트워크 문제로 실패하면 원인을 보고하고 같은 요청을 반복해서 게시하지 않는다. 이 스킬은 댓글 등록만 수행하며 코드 수정, 리뷰 결과 반영, PR 본문 수정, 머지는 별도 요청 없이 실행하지 않는다.
